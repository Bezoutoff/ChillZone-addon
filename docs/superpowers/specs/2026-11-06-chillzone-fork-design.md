# ChillZone: форк аддона Olympus — дизайн

Дата: 2026-11-06. Основа: `dnl-gentile/olympus-addon` @ `ed7a81e` (Olympus 1.5.1, MIT).
Репозиторий форка: `github.com/Bezoutoff/ChillZone-addon`, ветка работ `rebrand`.

## Цель

Перепись и общая сеть для гильдий ChillZone на WoW: Forever (Альянс) на базе Olympus:
перепись гильдий, иерархия, карта, указы, каналы и чат, доска групп, экономика (казна,
взносы, банк, крафт) и развлечения (арена, Farkle, тренировочная лотерея, «Церковь»).
Модерация остаётся в коде и интерфейсе как есть.

## Принятые решения

| Вопрос | Решение |
|---|---|
| Устройство | Сеть гильдий, общая перепись |
| Свои гильдии | Точный список: главная + встроенный список + список, подписанный владельцем; правило «слово в названии» удаляется |
| Обновления оригинала | Выборочно: свой бренд целиком, исправления переносятся скриптом `port-upstream.sh` |
| Лексика | Роли оригинала остаются (King, Lords, Captains, High Council, Treasurer, Church); меняются имена |
| Клиент, фракция | WoW: Forever, Альянс; код Орды остаётся, но без главной гильдии — Орда не участвует |
| Подход | Ребрендинг скриптом (`scripts/rebrand.py`) + ручные коммиты на логические места |

## 1. Имена и правила ребрендинга

Папки: `Olympus/` → `ChillZone/`, `Olympus_Arena/` → `ChillZone_Arena/`.
`OlympusSiteAggregate/` удаляется (раздел 3).

Правила `scripts/rebrand.py` (с учётом регистра, длинные совпадения первыми):

| Было | Стало |
|---|---|
| `Olympus` / `olympus` / `OLYMPUS` | `ChillZone` / `chillzone` / `CHILLZONE` |
| `Olympian(s)` / `olympian(s)` | `ChillZoner(s)` / `chillzoner(s)` |
| `/olympus`, `/oly` | `/chillzone`, `/cz` |
| `/ola`, `/ogarmy` | `/cza`, `/czarmy` |
| префикс `OLYMPUS` | `CHILLZONE` (9 из 16 допустимых) |
| каналы `OlympusNet` / `OlympusNetH` | `ChillZoneNet` / `ChillZoneNetH` |
| `~/.olympus` (ключи подписи) | `~/.chillzone` |

Глобальные имена (`ChillZoneDB`, `ChillZoneFrame`, `ChillZoneAPI`…) меняются тем же правилом,
поэтому форк и оригинал не конфликтуют в одном клиенте.

Скрипт не трогает: `LICENSE` (копирайт оригинала обязателен по MIT, своя строка добавляется
рядом), ссылки на оригинальный репозиторий в Credits, код и тесты правила названия (удаляются
в разделе 2), `Who.QUERY`/`Who.VARIANTS` (раздел 2).

Вручную:
- 153 упоминания Asmon/Asmongold в 30 файлах: по смыслу («Asmon's Olympus» → «ChillZone»,
  «Asmongold is Head of the Church» → «the King is Head of the Church»).
- 9 форм «олимпиец» в `ruRU.lua` → «участник ChillZone». Остальной русский перевод пишет бренд
  латиницей, падежи не страдают.

Бренд в текстах всех языков — латиницей «ChillZone» (не склоняется; механическая замена
безопасна). Кириллица «Чиллзон» — только в названиях гильдий.

Версия: числовая, продолжаем с 1.5.x (в коде есть сравнение с `1.1.2`, `Versions.FIRST`;
0.x сделал бы форк «старым клиентом»). База оригинала фиксируется в `UPSTREAM.md`.

Цвет `e6c35c` остаётся. Логотип: силуэт из группы VK (500×500, чёрный на белом) → золотой
`e6c35c`; `logo64.tga`, `logo128.tga` — на тёмно-бирюзовом квадрате, как в оригинале;
`emblem128.tga` — на прозрачном; белые области исходника (лицо, буква «M») прозрачные.
Также `docs/logo.png`. RGBA TGA, размеры как у оригинальных файлов.

## 2. Членство и полномочия

Своя гильдия = главная (`KING_GUILD`) ∨ встроенный список (`APPROVED_BUILTIN`) ∨ подписанный
список; исключённая (removed) по-прежнему не своя.

- Удаляются `Federation`, `OlympusWord`, `Sounds`, `Against`, кеш `federation`,
  `ns.NamedOlympus` (`Core.lua` ~1792–1915). Потребители: `ns.ApprovedOnly` (теряет условие
  на имя), `Diagnostics.lua:545` (строка упрощается).
- `ns.KING_GUILD = { Alliance = "Чиллзон" }` — ровно как в игре. Сравнение идёт через
  `guild:lower()`, а Lua не меняет регистр кириллицы, поэтому значение хранится в исходном
  регистре, а не в нижнем.
- `ns.APPROVED_BUILTIN = { Alliance = { "Чиллзон Навсегда" } }` — работает сразу после установки,
  без `/cz approved paste`. Новые гильдии — подписанным списком без нового релиза (лимит
  оригинала: 20 на фракцию). `ns.REMOVED_BUILTIN` — пустой.
- `Who.QUERY = 'g-"Чиллзон"'` (сервер ищет по подстроке — находит обе гильдии),
  `Who.VARIANTS = {}`.
- Пины людей пустые: `KING_CHARACTER`, `KING_NAME`, `KING_REALM`, `TREASURER`,
  `TREASURER_CHARACTERS`, `TREASURER_REALM`, `AUTHOR`, `AUTHOR_REALM`. Король, казначей,
  автор и реалм задаются подписанным списком (`council-sign.py king|treasurer|author|realm`).
- `IsTreasurer` сейчас требует гильдию `"olympus"` → сравнивать через `ns.IsKingGuild(guild)`.
- Ключ: `council-sign.py keygen` создаёт новую пару RSA-2048 (e = 3); приватная часть —
  `~/.chillzone/council-key.json` на этой машине (нужен бэкап); публичная (`N`, `MU`) —
  в `Sign.lua`.
- `API.AUTHORIZED` — пустой (хеш Discord-аддона Olympus удаляется).

Кириллица, что проверено: подписанный список гильдий принимает UTF-8 (`ApprovedName`: до 72
байт и 24 символов; `council-sign.py` — `isalpha()`); проверки `%a` на названиях гильдий
есть только в удаляемом правиле; лимиты длины гильдий в протоколе — 48–72 байта
(«Чиллзон Навсегда» = 31 байт). Риск, не проверенный до конца: лимиты длины **имён
персонажей** (например, `Crafters.lua:411` — `#name <= 24` байт) могут обрезать кириллические
имена «Имя Фамилия». Во время реализации — точечный аудит лимитов < 48 байт на именах и
тесты с кириллическими именами.

## 3. Что убираем и что гасим

- `OlympusSiteAggregate/`, `/olysite` (`Core.lua` ~3048, ~3106–3110, `GamepadRegistry.lua:70`),
  строки в `scripts/package.sh` и `scripts/deploy.sh`, `docs/SITE-AGGREGATE.md`.
- `Olympus_Link` — код не трогаем; после переименования ищет `ChillZone_Link`, которого нет,
  и бездействует.
- Ставки и рынки — выключены, как в оригинале (`Compliance.lua`, `scripts/bets-only.txt`).
- `.toc`: убрать `X-Curse-Project-ID`; `X-Website` → репозиторий форка; `Author` → «ChillZone
  addon contributors (based on Olympus)».
- Документация: вводная часть README переписывается под ChillZone; справка остальных разделов
  проходит через скрипт; удаляются `docs/olympus-*.jpg`, `docs/curseforge-logo-400.*`,
  `docs/RELEASE-1.2.*.md`.

## 4. Перенос исправлений из оригинала

- `scripts/rebrand.py`: правила раздела 1; режимы — по дереву (однократно) и фильтр патча
  (stdin → stdout), включая пути `Olympus/` → `ChillZone/`.
- `scripts/port-upstream.sh <коммит|диапазон>`: `git fetch upstream` → `git format-patch` →
  `rebrand.py` → `git am -3`. Конфликты в местах разделов 2–3 и текстах про Asmon ожидаемы и
  разбираются вручную.
- `UPSTREAM.md`: базовый коммит оригинала и список перенесённых коммитов.

## 5. Проверка и выпуск

- Нужен `luajit` (`sudo apt install luajit`); `python3-cryptography` уже стоит.
- После каждого шага — `bash scripts/check.sh` зелёный.
- Тесты правила названия (OLYMPVS, Olympoz…) заменяются тестами на список: чужая гильдия — не
  своя; «Чиллзон» (главная), «Чиллзон Навсегда» (встроенная), подписанная — свои; исключённая —
  не своя; пустые пины короля, казначея и автора ничего не ломают.
- `scripts/package.sh` → `dist/ChillZone-<версия>.zip` (`ChillZone`, `ChillZone_Arena`).
- Git: ветка `rebrand`, отдельные коммиты по шагам (ребрендинг скриптом, логика членства,
  удаления, логотип, тесты).

Проверка в игре (вручную, владелец):
1. Аддон загружается без ошибок, `/cz` открывает окно.
2. Клиент входит в канал `ChillZoneNet`.
3. Игроки из «Чиллзон» и «Чиллзон Навсегда» видят друг друга в переписи.
4. Подписанный список (король, реалм) расходится по клиентам; ГМ «Чиллзон» — король.
5. Экран «Вступить» у игрока вне гильдий находит участников через `/who`.

- Автор git-коммитов в этом репозитории.
